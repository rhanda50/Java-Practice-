# Java Practice (Maven)

This is a simple Maven project for Java practice.

## Requirements
- JDK 17 (or update `maven.compiler.release` in `pom.xml`)
- Maven 3.9+

## Common commands
```bash
mvn -v
mvn test
mvn -q -DskipTests package
```

## Project layout
- `src/main/java` application code
- `src/test/java` test code
